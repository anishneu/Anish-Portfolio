## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/your-username/portfolio-website.git
```

Navigate into the project directory:

```bash
cd portfolio-website
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm start
```

---

## 🎮 Unity WebGL Integration

This portfolio includes Unity WebGL projects integrated into the React application.

To add a Unity build:

1. Build your Unity project using WebGL
2. Copy the generated build files into the public folder
3. Load the Unity build inside React components
